📘 LESSON 4 — Strings

String

A string is a data type used to store text. 

word = "Python"

len()

Returns the number of characters. 

word = "Python"

print(len(word))
6

Concatenation

Joining strings together. 

first = "Hello"

second = "Python"

print(first + " " + second)
Hello Python

String Repetition

print("Hi " * 3)
Hi Hi Hi

Indexing

Index Meaning
0 First character
1 Second character
-1 Last character
-2 Second-to-last character 
word = "BOOKS"

print(word[0])
print(word[1])
print(word[-1])

O
S

✂️ Slicing

Slicing selects part of a string. 

word = "PYTHON"

print(word[0:3])
PYT 

word = "PYTHON"

print(word[::2])
PTO
⭐ Remember:

word[start:end:step]

The start is included. The end is NOT included.

🔤 String Methods

📘 LESSON 6 — List, Tuple & Dictionary

📋 LIST

A list is a general sequence object that can contain different types of items. Lists are mutable, meaning they can be changed. 

heroes = ["Nana", "Yss", "Miya", "Gloo"]

print(heroes)
['Nana', 'Yss', 'Miya', 'Gloo']

📋 List Methods

Method Purpose
append() Adds an item
insert() Adds at a specific index
remove() Removes an item
pop() Removes at a specific index
sort() Sorts items
reverse() Reverses the order

📌 TUPLE

A tuple is a sequence object like a list, but immutable. It cannot be changed. 

numbers = (10, 20, 30)

print(numbers)
(10, 20, 30)

📚 DICTIONARY

A dictionary is a collection of key-value pairs. 

person = {"name": "John", "age": 25}

print(person["name"])
John

📘 LESSON 8 — Functions

Defining a Function

def greet(name):

    print("Hello, " + name)

greet("Alice")
Hello, Alice

Return Statement

def add(a, b):

    return a + b

result = add(5, 3)

print(result)
8

Default Parameters

def greet(name="Guest"):

    print("Hello, " + name)

greet()

greet("Bob")
Hello, Guest
Hello, Bob

Multiple Return Values

def get_info():

    return "John", 25

name, age = get_info()

print(name, age)
John 25
